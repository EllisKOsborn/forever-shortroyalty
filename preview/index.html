Everything in the window uses the addon's own values: colours, sizes, spacing and motion timings are generated from UI/Theme.lua (node tools/preview-tokens.js), and the title font is the bundled Chakra Petch. Item icons are game files, so gear slots show the slot name instead. Tooltips are the game's own (approximated here). All names and numbers are made up. "Before" pictures are the old mock-ups from docs/images/.
